# نسخه آزمایشی سایت روی کامپیوتر خودتان

با این راهنما یک نسخه آزمایشی از سایت را روی کامپیوتر خودتان (ویندوز با WSL، لینوکس یا مک) اجرا می‌کنید و همه بخش‌ها را با داده نمونه می‌بینید و امتحان می‌کنید. **این برای سایت اصلی نیست.**

ویژگی‌های نسخه آزمایشی:

- بالای همه صفحه‌ها نوار «نسخه آزمایشی» دیده می‌شود.
- درگاه پرداخت آزمایشی است و پول واقعی جابه‌جا نمی‌شود. ایمیل و پیامک واقعی هم فرستاده نمی‌شود؛ متن ایمیل‌ها در همان پنجره ترمینال چاپ می‌شود.
- محصولات، فروشنده‌ها و سه درخواست عضویت نمونه از پیش ساخته شده‌اند.
- تغییراتی که می‌دهید در فایل `demo.sqlite3` می‌مانند.
- سایت فقط روی همین کامپیوتر باز می‌شود و دیگران آن را نمی‌بینند.

## بار اول (حدود ۱۰ دقیقه)

1. در ویندوز، **Ubuntu** (WSL) را از منوی Start باز کنید.
2. این دو خط را بچسبانید و Enter بزنید:

   ```
   git clone https://github.com/jafarmrt/fairtrade-iran.git ~/fairtrade-iran
   bash ~/fairtrade-iran/deploy/local/run-demo.sh
   ```

   اگر پیغام داد که `python3-venv` لازم است، این را بزنید و خط دوم را دوباره اجرا کنید:

   ```
   sudo apt update && sudo apt install -y python3-venv
   ```

3. وقتی نوشت `Starting development server`، در مرورگر ویندوز باز کنید: <http://localhost:8000/fa/>

پنجره Ubuntu را تا وقتی با سایت کار دارید باز بگذارید. برای خاموش کردن سایت در آن پنجره **Ctrl+C** را بزنید.

## دفعه‌های بعد

```
bash ~/fairtrade-iran/deploy/local/run-demo.sh
```

همین یک خط آخرین تغییرات کد را هم از GitHub می‌گیرد. داده‌ها را پاک نمی‌کند.

برای برگشتن به داده‌های نمونه تمیز:

```
RESET=1 bash ~/fairtrade-iran/deploy/local/run-demo.sh
```

## حساب‌های آزمایشی

رمز همه حساب‌ها `demo12345` است. برای رمزی دیگر، اسکریپت را این‌طور اجرا کنید: `DEMO_PASSWORD=رمز-دلخواه bash ~/fairtrade-iran/deploy/local/run-demo.sh`

| نام کاربری | چه چیزی را نشان می‌دهد | ورود از |
|---|---|---|
| `demo-admin` | مدیر کل؛ همه بخش‌های پنل مدیریت | <http://localhost:8000/admin/> |
| `demo-secretariat` | کارمند دبیرخانه؛ فقط دسترسی‌های گروه دبیرخانه | <http://localhost:8000/admin/> |
| `demo-member` | عضو «ارموز»؛ پنل اعضا (پروفایل، محصولات، سفارش‌ها) | «ورود اعضا» در بالای سایت |

## پرداخت آزمایشی

یک محصول از ارموز، پاپیتال، تیدا، چاگرد یا مهرباف به سبد بیفزایید، سفارش را ثبت کنید و «پرداخت آنلاین» را بزنید. صفحه درگاه آزمایشی باز می‌شود و می‌توانید پرداخت موفق یا ناموفق را انتخاب کنید.

## اگر کار نکرد

- اگر `localhost:8000` در مرورگر باز نشد، بررسی کنید پنجره Ubuntu هنوز باز است و خطایی نشان نمی‌دهد.
- اگر نصب بسته‌ها (pip) خطا داد و در خطا `Temporary failure in name resolution` آمد، Ubuntu به سرور بسته‌های پایتون (`files.pythonhosted.org`) نمی‌رسد. این از داخل ایران زیاد پیش می‌آید و VPNهای ویندوزی (مثل v2rayN) معمولاً ترافیک WSL را عبور نمی‌دهند. راه‌حل:

  1. DNS را روی سرورهای ایرانی بگذارید:

     ```
     sudo bash -c 'printf "nameserver 178.22.122.100\nnameserver 78.157.42.100\n" > /etc/resolv.conf'
     ```

     اگر بعد از ری‌استارت ویندوز دوباره عوض شد، یک بار این را هم بزنید تا WSL آن را بازنویسی نکند: `sudo bash -c 'printf "[network]\ngenerateResolvConf = false\n" >> /etc/wsl.conf'`

  2. اسکریپت را یک بار با آینه ایرانی بسته‌ها اجرا کنید. آینه به خاطر سپرده می‌شود و دفعه‌های بعد همان دستور همیشگی کافی است:

     ```
     PIP_INDEX_URL=https://mirror-pypi.runflare.com/simple bash ~/fairtrade-iran/deploy/local/run-demo.sh
     ```

- بسته‌ها فقط بار اول (و هر وقت فهرست بسته‌ها در کد عوض شود) دانلود می‌شوند؛ دفعه‌های بعد سایت بدون دانلود بالا می‌آید.
- چند خط آخر پنجره Ubuntu را برای تیم فنی بفرستید.

## جزئیات فنی

- `deploy/local/run-demo.sh` یک virtualenv در `.venv` می‌سازد و بسته‌ها را جز psycopg نصب می‌کند. سپس با تنظیمات `fairtrade.settings.dev` و `DEMO_MODE=1` پایگاه داده `demo.sqlite3` را آماده می‌کند، `seed_demo` را اجرا می‌کند و سرور آزمایشی Django را روی `127.0.0.1` بالا می‌آورد.
- `seed_demo` فقط با `DEMO_MODE=1` یا DEBUG اجرا می‌شود و روی سایت اصلی کاری نمی‌کند.
- برای نسخه آزمایشی روی اینترنت (برای دیگران)، آن را با `deploy/install.sh` روی یک VPS بالا بیاورید (راهنما: [deploy-fa.md](deploy-fa.md)). کافی است `DEMO_MODE=1` و `PAYMENT_ALLOW_TEST_GATEWAY=1` در `.env` گذاشته شود.

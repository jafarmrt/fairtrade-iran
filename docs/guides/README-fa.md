# راهنماهای PDF

دو راهنمای فارسی با تصویرهای واقعی از سایت:

| فایل | برای چه کسی |
|---|---|
| [admin-guide-fa.pdf](admin-guide-fa.pdf) | کارکنان و داوطلبان خانه در پنل مدیریت (`/admin/`): نقش‌ها، صفحه‌ها و خبرها، اسناد، پرونده‌های عضویت، اعضا و حق عضویت، فروشگاه و سفارش‌ها، شکایات، مجمع عمومی، تنظیمات، پیامک، فهرست کارهای هر گروه |
| [user-guide-fa.pdf](user-guide-fa.pdf) | بازدیدکنندگان و خریداران، متقاضیان عضویت، و اعضا در پنل اعضا (`/fa/panel/`) |

## ساختن دوباره

اگر ظاهر یا مراحل کاری در سایت عوض شد، متن را در `admin.html` یا `user.html` درست کنید و بعد از ریشهٔ مخزن بزنید:

```bash
bash docs/guides/make.sh
```

این دستور یک پایگاه دادهٔ نمایشی جدا (`docs/guides/work/`) می‌سازد، داده‌های نمونه (`seed_demo` و `extra_demo.py`) را می‌ریزد، سایت را روی `127.0.0.1:8000` بالا می‌آورد، همهٔ تصویرها را از نو می‌گیرد (`shoot.js`) و هر دو PDF را می‌سازد (`build.js`). حدود ده دقیقه طول می‌کشد.

پیش‌نیازها: محیط `.venv` پروژه، Node.js با Playwright (`npm i -g playwright` و `npx playwright install chromium`) و `pypdf` برای پایتون.

## فایل‌ها

- `guide.css`: شکل چاپی مشترک (رنگ‌های طلایی و سرمه‌ای برند، قلم وزیرمتن، شماره‌های فارسی صفحه).
- `admin.html` و `user.html`: متن راهنماها. هر فصل یک `<section class="chapter" data-toc="…">` است و فهرست خودکار از آن ساخته می‌شود.
- `shoot.js` و `lib.js`: گرفتن تصویرها و گذاشتن دایره‌های شماره‌دار روی آن‌ها. شمارهٔ هر دایره باید با شمارهٔ متن زیر تصویر یکی باشد.
- `build.js` و `outline.py`: چاپ PDF با Chromium در دو مرحله (مرحلهٔ دوم شمارهٔ صفحه‌ها را در فهرست می‌نویسد).
- `extra_demo.py`: داده‌هایی که `seed_demo` ندارد و تصویرها لازم دارند (حق عضویت، مجمع در حال برگزاری، ورود پیامکی).
